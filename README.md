# Ipeleng Mkhize – Front-End Portfolio

Plain HTML, CSS and JavaScript. No build step, no framework.

## View it
Double-click `index.html`, or open it in VS Code with the Live Server extension.

## Structure
```
index.html                          Home: hero, about, skills, projects, contact
projects/service-management-live.html   Case study
assets/css/styles.css               All styles (colour tokens at the top; dark mode included)
assets/js/main.js                   Theme toggle + mobile menu
```

## Before you share it (search for "EDIT ME")
- Contact links in `index.html`: personal email, LinkedIn, GitHub
- Your city in the About facts
- Rewrite the About paragraphs in your own voice
- Add real, shareable outcome numbers to the case study

## Confidentiality
Service Management Live is an internal tool. The portfolio describes what was built
and how, using an illustrative mock-up with sample data. Don't add screenshots
of real data, colleague names, internal URLs or source code without approval.

## Publishing (free)
Push this folder to a public GitHub repo named `<username>.github.io` and enable
GitHub Pages. Use a personal GitHub account, not the work organisation.
